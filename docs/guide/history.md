# History and playback

Every transmission is recorded and listed in the history panel, with its channel, time, radio IDs where the system provides them, and a transcript once [transcription](transcription.md) finishes.

## Views

| View | Shows |
|---|---|
| **Recent** | Live transmissions as they arrive. |
| **Favorites** | Recordings you have starred. |
| **Browse** | Everything, organised as Year → Month → Day → Channel. |

The **Browse** view opens with an activity heatmap: how busy each hour of each weekday has been over the last four weeks, in your local time.

In **Recent** and **Favorites** you can filter to **Tone-outs** to see only transmissions that followed a [fire tone-out](fire-tones.md).

## Search

Type in **Search logs…** to search by transcript text, channel name or frequency.

## Playing a recording

Click play on any entry. A player bar appears at the bottom with:

- Play / pause and a seek bar. With the seek bar focused, the arrow keys move 5 seconds and ++home++ / ++end++ jump to the start or end.
- **Playback speed**.
- **Download**, to save the recording.

Each entry also has its own **Download** and **Delete** buttons. Delete asks for confirmation first: it removes the audio file as well as the entry, and cannot be undone.

## Favorites

Click the star on a recording to keep it in **Favorites**. Starred recordings are never removed by automatic cleanup.

## Automatic cleanup

To stop the disk filling up, OpenScanner deletes the **oldest non-favorite** recordings when free space on the recordings disk drops below 2 GB, until space recovers.

To clear everything at once, use **Delete All Recordings** in [Settings → Storage](settings.md#storage).

## PowerDMS daily log

If you set a PowerDMS department in [Settings → Integrations](settings.md#integrations), each day in the **Browse** view gets a button that opens that day's PowerDMS daily log, when one exists.
