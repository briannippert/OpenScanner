# Radio aliases

Digital systems identify radios and talkgroups by number. Aliases let you replace those numbers with names, so the history reads `Engine 4` instead of `1234567`.

## Naming an ID

Open **Radio Aliases** from the header. It lists the IDs OpenScanner has heard in the last 7 days, grouped by channel:

- **Source IDs (SRC)** — individual radios.
- **Talkgroups (TG)** — groups of radios.

Type a display name next to an ID to alias it. The name is then used wherever that ID appears.

If the list is empty, no IDs have been heard yet. They appear after digital transmissions that carry them have been received.

## Export and import

The export and import buttons in Radio Aliases save your aliases to a file and load them back. Use them to back up your names or copy them to another OpenScanner device.
